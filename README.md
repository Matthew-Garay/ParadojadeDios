# Paradoja de Dios

Practica de IA en Prolog. El archivo `listasmemberyappend.pl` trae ejercicios de `member/2` y `append/3`, y un dialogo por consola que pregunta sobre el mal, la omnisciencia y el libre albedrio hasta llegar a una conclusion segun las respuestas.

El reporte de la practica esta en `P6. Ejercicio de la Paradoja de Dios.pdf`.

## Requisitos

SWI-Prolog.

## Uso

```bash
swipl listasmemberyappend.pl
```
